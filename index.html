OpenTalk

Speak about it

An AI-powered voice interface for
creating, editing, and transforming
text, anywhere on your laptop.

Unlike traditional speech-to-text solutions, OpenTalk incorporates intelligent text processing, natural language commands, and AI-assisted editing capabilities. This enables users to not only dictate content but also refine, restructure, and interact with existing text using their voice.

A key differentiator is OpenTalk’s bring-your-own-subscription approach, which enables users to leverage compatible AI services they already have access to, reducing the need for additional recurring subscriptions and offering greater flexibility over their AI infrastructure.

Four methods to use OpenTalk

Dictation Mode

Speak into the field you are already using. OpenTalk can remove fillers, apply spoken corrections, and format the transcript using Default, Minimal, Casual, Professional, or Extensive cleanup.

Assistant Mode

Select text in a supported Windows control, then record an instruction. Only the selected text and spoken instruction are used, and the revision is reviewed before anything changes.

Command Mode

Describe the text you need and receive inert text back. There is no browsing, tool use, file access, software control, or message sending.

Meeting Mode

Record a meeting or lecture from your selected microphone and playback device. Add bookmarks while it runs, then review the transcript, summary, minutes, and tasks locally in the Hub.
